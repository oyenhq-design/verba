# Verba

Folders:

- `verba-web`: Public marketing website for verba.com.
- `verba-app`: User application for app.verba.com.

Future:

- `verba-engine`: Document processing and writing-analysis service.

## Development

To run the marketing website:
```bash
cd verba-web
npm run dev
```

To run the application:
```bash
cd verba-app
npm run dev
```
